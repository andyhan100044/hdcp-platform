# 自动翻译流程图

## 🔄 完整流程

```
┌─────────────────────────────────────────────────────────────┐
│                    开始翻译流程                               │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 1️⃣ 提取英文原文                                                │
│    - 读取 apps/web/src/locales/en.json                      │
│    - 扁平化嵌套对象 (nav.home → nav.home)                   │
│    - 生成翻译键列表                                            │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 2️⃣ 批量 DeepL 翻译                                              │
│                                                               │
│  for (each language in [zh-CN, es, fr, ...]) {               │
│    ┌─────────────────────────────────────┐                    │
│    │ 批量翻译 (每批 50 个键)             │                    │
│    │                                    │                    │
│    │  "Hello" → "你好"                   │                    │
│    │  "Save" → "保存"                    │                    │

│    └─────────────────────────────────────┘                    │
│    ↓                                                           │

│  }                                                            │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 3️⃣ LLM 质量校核                                                │
│                                                               │
│  for (each translation) {                                    │
│    ┌─────────────────────────────────────┐                    │
│    │ GPT-4 分析                          │                    │
│    │                                    │                    │
│    │ 输入:                               │                    │
│    │  - 英文原文: "Save"                 │                    │
│    │  - 中文翻译: "保存"                 │                    │
│    │  - 翻译键: common.save              │                    │
│    │                                    │                    │
│    │ 评估维度:                           │                    │
│    │  ✓ 准确性    (1-10 分)              │                    │
│    │  ✓ 流畅性    (1-10 分)              │                    │
│    │  ✓ 文化适配  (1-10 分)              │                    │
│    │  ✓ 术语一致  (1-10 分)              │                    │
│    │  ✓ 格式保留  (1-10 分)              │                    │
│    └─────────────────────────────────────┘                    │
│    ↓                                                           │
│    生成:                                                       │
│    {                                                           │
│      correctedText: "保存",      // 改进后翻译               │
│      score: 0.92,               // 质量分数 (0-1)            │
│      issues: [],                 // 问题列表                 │
│      suggestions: [],            // 建议                     │
│      approved: true              // 是否自动通过             │
│    }                                                           │
│  }                                                            │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 4️⃣ 质量筛选                                                    │
│                                                               │
│  分数 ≥ 0.8?  ───────────┐                                   │
│     │                    │                                   │
│     ▼                    │                                   │
│  ✅ 自动通过              │                                   │
│     │                    │                                   │
│     └──────────┬─────────┘                                   │
│                │                                            │
│                ▼                                            │
│            ❌ 需人工审核                                        │
│                                                               │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 5️⃣ 生成翻译文件                                                │
│                                                               │
│  将结果转换为嵌套 JSON 对象:                                   │
│                                                               │
│  {                                                            │
│    "common": {                                                │
│      "save": "保存",                                          │
│      "cancel": "取消"                                         │
│    },                                                         │
│    "nav": {                                                   │
│      "home": "首页"                                           │
│    }                                                          │
│  }                                                            │
│                                                               │
│  保存到: apps/web/src/locales/{locale}.json                  │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 6️⃣ 生成报告                                                    │
│                                                               │
│  📄 translation-report-{locale}.md                           │
│     - 翻译统计                                                 │
```

## 🔀 并行处理优化

```
时间轴:

第1秒: ┌──────────┐  提取英文原文 (所有语言共用)
       └──────────┘

第2秒: ┌──────┐ ┌──────┐ ┌──────┐  DeepL 翻译 (并行)
       │ zh-CN│ │ es   │ │ fr   │
       └──────┘ └──────┘ └──────┘

第3秒: ┌──────┐ ┌──────┐ ┌──────┐  LLM 校核 (并行)
       │ zh-CN│ │ es   │ │ fr   │
       └──────┘ └──────┘ └──────┘

第4秒: ┌──────────┐  生成文件
       └──────────┘

第5秒: ┌──────────┐  生成报告
       └──────────┘
```

---

## ⚡ 性能优化点

### 1. 批量处理
```
❌ 逐个翻译: 1000键 × 7语言 × 1秒 = 7000秒
✅ 批量翻译: 1000键/50批 × 7语言 × 1秒 = 140秒
  提升: 50倍
```

### 2. 并行处理
```
❌ 串行翻译: 7语言 × 30秒 = 210秒
✅ 并行翻译: 30秒 × 1轮 = 30秒
  提升: 7倍
```

### 3. 智能缓存
```
✅ 已翻译的键自动跳过
✅ 评分高的键直接通过
✅ 失败重试最多 3 次
```

## 📊 质量保证流程

```
输入: "Save" → "保存"
      ↓
GPT-4 评估:
┌─────────────────────────────────────┐
│ 1. 准确性: 9/10 ✓                  │
│    - 意思完全一致                   │
│                                     │
│ 2. 流畅性: 9/10 ✓                  │
│    - 符合中文表达习惯                │
│                                     │
│ 3. 文化适配: 10/10 ✓                │
│    - 无文化敏感内容                  │
│                                     │
│ 4. 术语一致: 8/10 ✓                │
│    - 与其他按钮保持一致              │
│                                     │
│ 5. 格式保留: 10/10 ✓                │
│    - 格式完全一致                    │
│                                     │
│ 总分: (9+9+10+8+10)/5 = 9.2/10     │
│ 换算: 0.92/1.0                     │
└─────────────────────────────────────┘
      ↓
  ✅ 评分 0.92 > 0.8
      ↓
  ✅ 自动通过
      ↓
  💾 保存翻译
```
